## Scheduling all 30 days at once (about 20 minutes, one time)
1. **Facebook + Instagram:** business.facebook.com → Planner → Create post → pick both the Page and Instagram → upload the day's image, paste the caption (Instagram caption for IG) → Schedule for 10:30. Repeat per day; Meta lets you schedule up to 75 days ahead.
2. **LinkedIn page:** on the page, Start a post → add image → paste caption → clock icon → set date and 10:30. LinkedIn schedules up to 3 months ahead.
3. Everything is in `schedule.csv` (opens in Excel) and `captions.md`.
